# 🏨 Hotel Booking Management System

A full-stack Hotel Booking Management System that enables users to browse hotels, book rooms securely, and manage reservations through an intuitive web interface.

Built using **Spring Boot**, **React**, **JWT Authentication**, **MySQL**, and **Stripe Payment Gateway**.

---

## 📌 Features

### 👤 User Features

- User Registration & Login
- JWT-based Authentication
- Browse Available Rooms
- Room Booking
- Booking History
- Secure Online Payments using Stripe
- Email Booking Confirmation

### 🛠️ Admin Features

- Add New Rooms
- Update Room Details
- Delete Rooms
- Upload Room Images
- Manage Bookings
- View Customer Information

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/archanakamal/Hotel-Booking-Management-System.git
```

---

## Backend

```bash
cd HotelBookingBackend
```

Configure MySQL credentials inside:

```
application.properties
```

Run the Spring Boot application.

---

## Frontend

```bash
cd hotel-react-frontend
npm install
npm start
```
